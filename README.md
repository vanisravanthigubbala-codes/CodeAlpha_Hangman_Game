# 🎮 Hangman Game - Python

Welcome to the Hangman Game! This is a simple, interactive command-line word-guessing game built with Python. 
This project was developed as part of my *Python Programming Internship at CodeAlpha*.

## 📝 Game Rules (How to Play)
1. The computer chooses a secret word and shows you blanks (_ _ _) for each letter.
2. You need to guess one letter at a time.
3. If your guess is correct, the letter will appear in its correct position.
4. If your guess is wrong, you lose one attempt.
5. You win if you guess all the letters before running out of attempts!

## ✨ Features
* Clean and easy-to-use Command Line Interface (CLI).
* Real-time tracking of remaining attempts.
* Simple logic suitable for basic text-based gaming.

## 🚀 How to Run the Code
1. Make sure you have Python installed on your system.
2. Download the Hangman game.py file from this repository.
3. Open your terminal or command prompt.
4. Run the file using the command: python "Hangman game.py"
